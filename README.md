KovaaK's Customisation Collection 🎯

A collection of custom themes, sounds, crosshairs and UI colour palettes for KovaaK's FPS Aim Trainer.

What's Included
Themes – Custom UI themes
Sounds – Custom sound effects
Crosshairs – Custom crosshairs
Palette.ini – Custom UI colours
Installation (Windows)

Palette.ini

Place Palette.ini into:

text
C:\Users\YOURNAME\AppData\Local\FPSAimTrainer\Saved\Config\WindowsNoEditor


Sounds & Crosshairs

Place both folders into:

text
C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer


Themes

Place the Themes folder into:

text
C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer\Saved\SaveGames

Installation (Linux / Steam Proton)

Sounds & Crosshairs

Place both folders into:

text
~/.local/share/Steam/steamapps/common/FPSAimTrainer/FPSAimTrainer/


Themes

Place the Themes folder into:

text
~/.local/share/Steam/steamapps/common/FPSAimTrainer/FPSAimTrainer/Saved/SaveGames/


Palette.ini

Place Palette.ini into:

text
~/.local/share/Steam/steamapps/compatdata/824270/pfx/drive_c/users/steamuser/AppData/Local/FPSAimTrainer/Saved/Config/WindowsNoEditor/


Steam App ID: 824270
