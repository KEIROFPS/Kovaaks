KovaaK's Customisation Collection 🎯

A collection of custom themes, sounds, crosshairs and UI colour palettes for KovaaK's FPS Aim Trainer.

What's Included
Themes – Custom UI themes
Sounds – Custom sound effects
Crosshairs – Custom crosshairs
Palette.ini – Custom UI colours
Installation (Windows)
Place Palette.ini in: C:\Users\YOURNAME\AppData\Local\FPSAimTrainer\Saved\Config\WindowsNoEditor
Place the sounds and crosshairs folders in: C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer
Place the Themes folder in: C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer\Saved\SaveGames
Installation (Linux / Steam Proton)
Place sounds and crosshairs in: ~/.local/share/Steam/steamapps/common/FPSAimTrainer/FPSAimTrainer/
Place Themes in: ~/.local/share/Steam/steamapps/common/FPSAimTrainer/FPSAimTrainer/Saved/SaveGames/
Place Palette.ini in: ~/.local/share/Steam/steamapps/compatdata/824270/pfx/drive_c/users/steamuser/AppData/Local/FPSAimTrainer/Saved/Config/WindowsNoEditor/
