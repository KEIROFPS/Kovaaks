🎯 KovaaK's Customisation Collection

A collection of custom themes, sound effects, crosshairs and UI colour palettes for KovaaK's FPS Aim Trainer.

Everything you need to customise your KovaaK's experience in one place!

📦 What's Included?
Folder / File	Description
Themes/	Custom UI themes and visual styles
sounds/	Custom in-game sound effects
crosshairs/	Custom crosshairs
Palette.ini	Custom UI colour palette
🖥️ Installation – Windows

1. Palette.ini

Place Palette.ini into:

text
C:\Users\YOURNAME\AppData\Local\FPSAimTrainer\Saved\Config\WindowsNoEditor


Replace YOURNAME with your Windows username.

2. Sounds & Crosshairs

Place the sounds and crosshairs folders into:

text
C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer


3. Themes

Place the Themes folder into:

text
C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer\Saved\SaveGames


Your final folder structure should look like:

text
FPSAimTrainer/
├── crosshairs/
├── sounds/
└── Saved/
    └── SaveGames/
        └── Themes/

🐧 Installation – Linux (Steam / Proton)

Linux installation is almost identical to Windows.

1. Sounds & Crosshairs

Place both folders into:

text
~/.local/share/Steam/steamapps/common/FPSAimTrainer/FPSAimTrainer/


2. Themes

Place the Themes folder into:

text
~/.local/share/Steam/steamapps/common/FPSAimTrainer/FPSAimTrainer/Saved/SaveGames/


3. Palette.ini

Linux requires a different location for the palette because KovaaK's runs through Steam Proton.

The Steam App ID is:

text
824270


Place Palette.ini into:

text
~/.local/share/Steam/steamapps/compatdata/824270/pfx/drive_c/users/steamuser/AppData/Local/FPSAimTrainer/Saved/Config/WindowsNoEditor/


If your Steam library is installed somewhere else, adjust the path accordingly.

⚠️ Important Notes
Back up your existing files before replacing anything.
Keep the folder names exactly as shown.
Make sure you place the folders in the correct directories.
Restart KovaaK's after installation if your changes aren't immediately visible.
